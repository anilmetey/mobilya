# mobilya

DENEME - Asırlık Masif Ahşap & Zanaatkar Mobilya Koleksiyonu Tanıtım Sitesi.

## Özellikler
- 🪵 Asırlık meşe ve kestane kirişlerinden kurtarılan masif zanaatkar mobilya kataloğu
- 🏛️ Mimari detaylı, sayfa ile uyumlu transparan mobilya arka planlı açılış ekranı (Splash Screen)
- 📱 Mobil ve masaüstü tam uyumlu (responsive) mimari header & mega menü
- 🏷️ NFC seri kimlik simülatörü ve mimari sipariş formu
- 📞 Doğrudan atölye arama ve iletişim entegrasyonu (Mersin Mezitli)

## Kurulum ve Çalıştırma
```bash
npm install
npm run dev
```

## Canlı Derleme (Production)
```bash
npm run build
```
